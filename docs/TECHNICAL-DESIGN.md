# AIGC 任务撮合平台 · 技术方案（MVP）

> 定位：连接**中小商家**（内容需求方）与**个人 AIGC 创作者**（供给方）的任务交易撮合平台，对标"AI 时代的猪八戒/Fiverr"。
> 平台形态：**微信小程序（商家+创作者双角色）+ PC Web 商家后台 + 平台管理后台**
> 建设方式：**外包开发 / AI 编程工具辅助**（创始人无技术背景）
> 商业模式假设：任务赏金托管制，平台抽佣 10%~20%

---

## 1. 选型总原则（为什么这么选）

| 原则 | 说明 |
|---|---|
| **外包人才池最大** | 技术栈必须是国内外包公司最熟的，换一家公司也能接手维护 |
| **主流 = AI 编程工具友好** | Cursor/Claude 等对主流栈（Java/Vue/MySQL）生成质量最高，便于自己后续用 AI 改代码 |
| **全托管云服务** | 不买物理机、不自建数据库/消息队列，运维成本趋近于零 |
| **模块化单体** | MVP 阶段一套后端服务搞定，绝不上微服务（那是 10 倍成本的开始） |
| **账号资产自持** | 小程序、支付商户号、云账号全部注册在自己名下，外包只有协作权限 |

## 3. 技术选型清单

| 模块 | 选型 | 理由 | 替代方案 |
|---|---|---|---|
| 小程序 | **uni-app + Vue3** | 一套代码，未来可低成本扩展 H5/App；外包普及率最高 | 微信原生（仅限只做微信端） |
| PC 商家后台 | **Vue3 + Element Plus** | 国内后台管理事实标准，组件齐全 | React + Ant Design |
| 平台管理后台 | **若依 RuoYi-Vue3 定制** | 外包最常用的后台脚手架，权限/菜单/日志开箱即用 | vue-element-admin |
| 后端 | **Java 17 + Spring Boot 3** | 外包人才最多、招聘/换供应商最容易、生态最成熟 | Node.js(NestJS)、Python(FastAPI)——若外包团队更擅长可替换，架构不变 |
| ORM | MyBatis-Plus | 国内外包生态标配 | JPA |
| 数据库 | **MySQL 8.0（腾讯云 TencentDB）** | 全托管、自动备份、免运维 | 自建 MySQL（不建议） |
| 缓存 | Redis（腾讯云） | 会话缓存、任务排行、接口防刷 | — |
| 文件存储 | **腾讯云 COS + CDN** | 图片/视频存储、加速、防盗链（选腾讯云与微信生态打通最顺） | 阿里云 OSS |
| 即时通讯 IM | **腾讯云 IM（含小程序 UIKit）** | 站内沟通必须（防跳单），自建 IM 成本极高 | 环信、融云 |
| 内容审核 | **腾讯云天御**（图片+文本） | AI 生成内容必须过机审，按量计费 | 阿里云内容安全 |
| 支付/资金 | **持牌机构「平台分账」**（汇付/易宝/通联等） | 见 §7.1——个人创作者结算无比例限制，资金存管合规 | 微信支付「分账」（30% 上限需提额）、电商收付通（创作者持照后） |
| 消息通知 | 微信订阅消息 + 腾讯云短信 | 任务状态变更通知（接单、交付、验收） | — |
| 部署 | **1 台云主机 + Docker Compose** | Nginx + 后端 Jar + 前端静态包一键部署，外包会做、换人也能维护 | K8s（MVP 阶段严重过度设计） |
| 接口文档 | Apifox / Swagger | 合同附件的一部分，验收依据 | — |
| 代码托管 | **自己名下的 Gitee/GitHub 私有仓库** | 源码资产归你，外包只提交代码 | — |

## 4. 核心业务流程（交易闭环）

### 4.1 主流程

```
商家                          平台                         创作者
 │                             │                             │
 ├─ 选任务模板（商品图/短视频…）  │                             │
 ├─ 填需求+上传素材 ────────────▶│ 任务审核（机审+人工抽审）        │
 ├─ 托管赏金（微信支付）─────────▶│ 资金进入微信侧托管账户           │
 │                             ├─ 任务上架，进入任务广场 ────────▶│
 │                             │                             ├─ 浏览/搜索任务
 │                             │   两种接单模式（后台可配置）：     │
 │                             │   A. 一口价抢单（先到先得）       │
 │                             │   B. 投标比稿（商家择优）─────────┤
 │                             │                              ├─ 投标（报价+方案+工期）
 │◀─────── 投标列表 ────────────┤                              │
 ├─ 选定创作者（中标）──────────▶│ 生成订单，冻结赏金               │
 │                             │◀─────────── 站内IM沟通 ────────┤
 │                             │◀─────────── 提交作品 ───────────┤
 │                             │ 作品机审（色情/违规/侵权初筛）      │
 │◀─────── 作品验收 ────────────┤                              │
 ├─ 验收通过 ──────────────────▶│ 微信分账：创作者得赏金×(1-佣金)   │
 │                             │           平台得佣金            │
 │◀─────── 互相评价 ────────────┤──────────────────────────────▶├─ 申请提现（T+1 审核打款）
```

### 4.2 异常流（必须写进需求文档，外包最容易漏的就是这些）

| 场景 | 规则 |
|---|---|
| 商家超时不验收 | 作品提交后 72h 未处理 → 自动验收通过（时间后台可配） |
| 商家驳回 | 每单含 N 轮免费修改（模板里定义，默认 2 轮），超出可加钱续轮 |
| 创作者超时未交付 | 到截止时间未提交 → 商家可取消并全额退款，创作者扣信用分 |
| 纠纷 | 任一方可发起仲裁 → 平台管理后台人工裁决（退款/放款/部分放款） |
| 撤稿 | 招募中可随时撤；有人接单后撤稿扣 10%~30% 违约金进创作者补偿池 |

## 5. 功能清单与版本规划

### MVP（第一期，上线必需）

| 端 | 功能 |
|---|---|
| **小程序（双角色）** | 微信授权登录；创作者/商家角色选择与切换；实名认证（身份证二要素）；商家企业认证；任务广场（分类/搜索/筛选）；任务详情；一口价抢单 / 投标+方案展示；我的订单（进行中/待验收/已完成）；提交作品（图片/视频/压缩包）；验收/驳回；互相评价（星级+标签）；钱包余额与流水；提现申请（银行卡绑定）；站内 IM；消息通知（订阅消息） |
| **PC 商家后台** | 账号注册登录（与小程序同账号体系）；任务模板化发布（商品图/模特图/短视频/详情页/文案/直播脚本 六类模板起步）；素材批量上传；任务管理（招募中/进行中/已完成）；投标者对比与中标；验收操作；充值与账单；发票申请（可后置） |
| **平台管理后台** | 任务审核；作品抽审；用户管理（封禁/信用分）；纠纷仲裁工单；提现审核（T+1 人工打款）；佣金比例/类目/超时规则等运营配置；基础数据看板（GMV、任务数、接单率、纠纷率）；内容安全审核记录 |

### V1.1（上线后 1~2 个月）

- 创作者等级体系（新手/进阶/认证创作者，等级决定可接任务金额上限）
- 创作者作品集主页（接单转化关键）
- 保证金机制（创作者缴保证金享优先派单）
- 邀请裂变（邀请商家/创作者得佣金减免）
- 数据看板增强

### V2（模式验证后）

- **平台内 AI 生成工具**：对接即梦/可灵/SD 等 API，"机器初稿 + 人工精修"混合交付，把工作流锁在平台内（护城河）
- 智能匹配推荐（任务↔创作者双向推荐）
- 企业月度订阅（包月内容服务）
- 案例市场（成品模板按份售卖）

## 6. 数据模型（核心表）

| 表 | 关键字段 | 说明 |
|---|---|---|
| `user` | openid、unionid、角色、昵称、头像、状态 | 微信登录主体，一个账号可双角色 |
| `real_name_auth` | 姓名、身份证号（加密存储）、二要素结果 | 个人实名 |
| `merchant_info` | 企业名、营业执照、对公/法人信息 | 商家认证 |
| `service_category` / `service_template` | 类目树；模板字段定义（需求表单、免费修改轮次、指导价） | 任务发布的模板化基础 |
| `task` | 标题、类目、需求描述、素材附件、赏金、截止时间、接单模式、状态机 | 状态：草稿→待支付→招募中→进行中→交付中→待验收→已完成/纠纷/已退款 |
| `task_bid` | 任务id、创作者id、报价、方案、工期 | 投标模式用 |
| `order` | 任务id、买卖双方、金额、佣金、各节点时间、状态 | 接单即成单 |
| `delivery` | 订单id、文件列表、说明、版本号、机审结果 | 每次提交一条，保留版本链 |
| `revision` | 订单id、轮次、驳回原因 | 修改轮次控制 |
| `review` | 订单id、评价方、星级、标签、评语 | 双向互评 |
| `wallet` / `wallet_flow` | 余额、冻结金额；流水类型（分账入账/提现/违约金） | 资金流水必须可对账 |
| `withdrawal` | 申请人、金额、银行卡、审核状态、打款凭证 | T+1 人工审核 |
| `payment_record` | 微信支付单号、分账回执、退款流水 | 与微信侧逐笔可对账 |
| `dispute` | 订单id、发起方、原因、凭证、仲裁结果 | 纠纷工单 |
| `admin_user` / `role` / `permission` | 若依自带 | 管理后台权限 |
| `sys_config` | 佣金比例、自动验收时长、驳回规则 | 运营参数后台可改，不发版 |

> 原则：**所有金额字段用"分"为单位的整数**存储（避免小数误差）；身份证/银行卡加密存储；核心表只增不删（用软删除 + 状态），保证资金可追溯。

## 7. 关键专项方案

### 7.1 资金与分账合规（⚠️ 本方案最高优先级）

**红线**：平台用自己公户收款，再私下打款给创作者 = **"二次清算"（二清），无支付牌照属违法**，支付渠道会直接冻结商户号。

**核心难点**：本平台的钱是"商家 → 个人创作者"，而**个人无法直接成为微信/支付宝的二级商户**（需要营业执照）。通道选择决定了能否落地：

| 通道 | 机制 | 个人创作者结算 | 适用性 |
|---|---|---|---|
| **持牌机构「平台分账」**（⭐ MVP 首选） | 汇付天下（斗拱）/ 易宝 / 通联 / 富友等持牌机构的平台分账产品：商家付款进机构存管户 → 验收后分账 → 个人凭身份证四要素入网结算提现 | ✅ 无比例限制，支持微信+支付宝+银联聚合 | 服务型交易平台的行业标准做法（猪八戒同类），签约 1–2 周 |
| **微信支付「分账」** | 平台普通商户开通分账功能，个人接收方（openid）分账 | ⚠️ 可行但**默认分账比例上限 30%**（创作者应得 85% 需向微信支付商务申请提额，审批不确定）；订单资金冻结期最长 180 天 | 仅适合快速验证，佣金制（平台只抽成）场景 |
| **微信「电商收付通」** | 平台型电商方案，资金存管微信侧，分账给二级商户 | ❌ 二级商户入驻**需要营业执照**（个体户/企业），个人不能入网 | V2 阶段：认证创作者引导注册个体户后切换 |

**MVP 推荐路径**：持牌机构平台分账（通道费约 0.2%–0.6% + 提现费，签约时谈量价）→ 验收通过触发分账 API（创作者 85% 入个人余额、平台 15% 留存）→ 个人 T+1 提现银行卡（机构代发）。资金全程存管在持牌机构备付金账户，平台公户不碰钱。

**创作者个税**（第二道合规关）：个人取得劳务报酬适用 20%–40% 预扣率，直接分账会重挫创作者积极性。行业标准解法：
1. MVP 期：单笔/单月小额（如 ≤¥500/单、≤¥5,000/月）直接分账，平台按劳务报酬代扣代缴申报；超出部分引导走灵活用工
2. V1.1 接入**灵活用工平台**（个体工商户注册 + 经营所得核定征收，综合税负约 1.5%–3%，平台取得 6% 专票可抵扣）——注意 2024 年后该领域监管收紧，只选持牌国资背景平台
3. 绝对禁止：现金/私人账户私下结算

**绝对禁止**：个人码收款、公户收款再手动转账。

### 7.2 内容审核与 AIGC 合规

- 所有上传素材（商家需求附件）与交付作品，入库前过**腾讯云天御机审**（色情、暴恐、涉政、广告法敏感词），机审可疑进管理后台人工复审队列
- 按《人工智能生成合成内容标识办法》（2025.9 起施行），平台内 AI 生成内容需加**显式"AI 生成"标识**——创作者提交作品时勾选声明 + 平台展示角标，规则写进用户协议
- 用户协议必备条款：AI 作品版权归属约定、禁止生成侵权内容（明星脸/品牌 LOGO）、侵权投诉-下架-处罚流程（参考"通知-删除"规则，这是平台免责的关键）

### 7.3 IM 与防跳单

- 站内沟通用**腾讯云 IM**（小程序 UIKit 现成 UI，几百元/月起）
- 防跳单：IM 消息敏感词过滤（微信号/手机号/支付宝账号等正则 + 语义），命中即屏蔽并警告；任务详情页明示"平台外交易无保障"
- 支付/交付动作全部限制在平台内闭环，评价与售后权益只对站内订单生效

### 7.4 文件存储与防盗链

- 商家素材、交付作品统一存 COS 私有桶，通过**带签名的临时 URL**（有效期如 2h）访问
- CDN 加速 + Referer/UA 防盗链；交付作品在验收前仅买卖双方可见
- 视频类任务交付物较大：COS 分片上传，单文件上限 5GB

### 7.5 提现与风控

- 提现条件：实名认证 + 银行卡四要素校验 + T+1 到账（人工审核大额）
- 风控规则：同设备多账号识别、新账号首单延迟放款、频繁拒单降信用分（信用分决定派单优先级与可接金额上限）

## 10. 外包合作管理清单（针对你的情况，重点看这节）

### 10.1 账号资产——全部自己注册，外包只给协作者权限

| 资产 | 注册主体 | 说明 |
|---|---|---|
| 微信小程序账号 + 微信支付商户号 | 你的公司 | 外包以"项目成员"身份开发 |
| 腾讯云主账号 | 你的公司 | 给外包子账号；**账单绑你的支付方式** |
| 域名 | 你本人/公司 | 备案要用 |
| Gitee/Git 私有仓库 | 你本人 | 外包每天推送代码，你持有仓库 |

> 这样无论外包出什么问题，代码、账号、数据都在你手里，换一家公司可无缝接手。

### 10.2 合同要点

- 知识产权：**源码、设计稿、文档全部归你**（委托开发合同默认归属委托方，但要写明）
- 交付物清单：源码 + 数据库脚本 + 接口文档（Apifox）+ 部署手册 + 测试报告 + 3 分钟演示视频
- 付款：按上表 30/30/30/10 里程碑，**每个里程碑按功能清单逐项验收后付款**
- 免费维护期：上线后 3 个月 bug 免费修复（写进合同）
- 需求冻结：M0 确认后改需求走变更单，防止互相扯皮

### 10.3 怎么判断外包靠不靠谱

- 直接问技术栈："Java Spring Boot + Vue3 + MySQL + uni-app 能做吗"——答不上来或强行推销自研框架的，pass
- 要看他们用若依/uni-app 做过的**真实上线案例**（扫码体验），而不是 PPT
- 报价区间参考：正规外包公司 20–40 万；小团队 10–20 万；远程兼职 5–10 万（风险最高）。**低于 8 万说能全做的，大概率烂尾**
