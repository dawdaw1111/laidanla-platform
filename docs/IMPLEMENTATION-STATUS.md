# 当前实现范围

## 已实现

PC 商家与创作者的 20 个前端页面、共享导航与侧栏、分类搜索与分页、任务模板表单、上传预览、草稿、投标与中标演示、版本交付、驳回和验收演示、钱包与提现记录、账单导出、会话、资料编辑、认证状态演示。界面已完成统一精修。

## 尚未实现

正式后端 API、数据库、真实账号体系、实名认证/企业认证、对象存储与内容审核、真实 IM、支付/分账/退款/提现、服务器定时任务、平台运营后台、微信小程序以及生产部署运维。

## 后续交易闭环

需要按统一订单状态机实现正常及异常流程，完成权限控制、并发抢单、支付回调幂等、分账与退款、资金对账、超时任务、运营审核及仲裁。资金渠道需结合主体资质与渠道实际能力确认；历史 PRD 与技术方案对支付通道的描述尚需统一。

当前仓库作为后续开发的前端基础；已有演示测试不能替代真实支付、多人并发和生产环境验收。
