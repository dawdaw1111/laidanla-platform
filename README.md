# 来单啦 · AIGC 任务撮合平台

面向商家与 AIGC 创作者的 PC 前端，包含任务发现、发布、投标、订单交付、验收、钱包、财务、消息、个人资料与认证等 20 个页面。采用 Vue 3、Vue Router、Element Plus 和 Lucide，视觉使用钴蓝与银色流体。

> **当前完成的是可交互的前端演示。** 登录、认证、支付、分账、提现、IM、审核和自动验收未接入正式后端；订单与资金变化是当前浏览器中的示例数据，不发生真实交易。

## 本地运行

需要 Node.js 22+、npm。

```sh
npm ci
npm run dev
```

开发预览：http://127.0.0.1:5174

- 全部页面：http://127.0.0.1:5174/preview.html
- 原版与精修版截图对比：http://127.0.0.1:5174/review.html
- 商家工作台：http://127.0.0.1:5174/merchant
- 创作者订单：http://127.0.0.1:5174/creator/orders

Windows 也可双击「启动精修副本.cmd」；它会通过 npx 使用 Node.js 22。开发端口固定为 5174，被占用时会直接提示。

## 构建与检查

```sh
npm run build
npm run preview
```

生产预览使用 4174。应用使用 history 路由；部署到静态托管时，业务路径需回退到 index.html。

已完成 15 项 Chrome 端到端测试，以及 20 页在 1440 / 1024 / 390px 下的 60 次渲染检查、五类发布表单的 10 次补充检查。生产构建与预览检查通过；公共 JS 包仍有超过 500KB 的体积提示。

测试需要先启动开发服务，并安装 Google Chrome：

```sh
npm run test:e2e
```

可用 PREVIEW_URL 指定其他测试地址。测试使用独立浏览器上下文，不访问个人 Chrome 资料；页面截图输出到项目同级「来单啦-精修版验收」目录。

## 演示流程

1. 登录页选择身份、勾选协议，点击「使用演示账号体验」，无需真实手机号。
2. 认证中心使用虚构演示资料体验审核与通过状态。
3. 商家选择模板、填写需求、模拟托管，并在任务管理中体验审核上架。
4. 创作者投标或查看订单，上传本地示例文件并提交交付。
5. 个人中心确认切换商家身份，体验驳回修改与验收结算。
6. 钱包、提现、消息、延期和评价仅改变本地演示状态。

示例数据保存在 laidanla-refined-demo-v1；清除当前站点数据可重置。文件仅生成临时本地预览，不上传服务器，刷新后可能需要重选。身份表单内容不持久化。

## 项目结构

```text
src/pages/            页面
src/components/       导航、侧栏、任务卡片、表格、上传等组件
src/lib/              本地演示状态与操作
src/router.js         路由
src/refinement*.css   精修版界面规范与页面样式
public/assets/        品牌图、作品示例、字体和截图
public/preview.html   全部页面入口
public/review.html    原版与精修版截图对比
scripts/              检查脚本
tests/                Playwright 端到端测试
docs/                 产品需求与技术规划
```
