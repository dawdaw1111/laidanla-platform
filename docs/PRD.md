## 1. 产品概述

### 1.1 一句话定位

连接中小商家（内容需求方）与个人 AIGC 创作者（供给方）的任务交易撮合平台：商家模板化发布任务并托管赏金 → 创作者抢单/投标 → 平台内交付验收 → 分账结算。

### 1.2 目标用户与核心场景

| 角色 | 画像 | 典型场景 |
|---|---|---|
| 商家 | 淘宝/拼多多/抖音中小商家、品牌运营，月内容预算 500–50,000 元 | 大促前需 5 张商品主图，传统外包 ¥1500/3 天，平台 ¥600/1 天交付 |
| 创作者 | 掌握 Midjourney/SD/即梦/可灵 等工具的个人，学生/兼职/自由职业 | 用业余时间接单，月增收 2000–8000 元 |
| 平台运营 | 自有团队 2–5 人 | 审核、仲裁、风控、参数调优 |

### 1.3 核心价值

- 商家：成本降 50%+、当天有人接、赏金托管有保障
- 创作者：需求标准化（模板降低沟通成本）、担保交易、T+1 提现
- 平台：交易佣金（默认 15%，创作者侧收取）

### 1.4 名词表

| 名词 | 定义 |
|---|---|
| 赏金 | 商家发布任务时托管的总金额（含创作者所得与平台佣金） |
| 托管 | 支付成功后资金由微信支付「电商收付通」存管，平台公户不碰资金 |
| 抢单 | 一口价模式：先到先得，点击即锁定订单 |
| 投标 | 比稿模式：创作者提交报价+方案，商家择优中标 |
| 轮次 | 免费修改次数，驳回一次消耗一轮 |
| 分账 | 验收通过后，赏金按佣金比例拆分：创作者实得 = 赏金 × (1 − 佣金率) |
| 信用分 | 交易行为分（初始 100），影响派单权重与接单权限 |
| 机审 | 内容安全 API 自动审核（腾讯云天御：图片+文本） |

### 1.5 MVP 范围边界

**做（In Scope）**：小程序双角色端（P01–P12 全部功能）、PC 商家后台（M01–M05）、平台管理后台（A01–A05）、微信支付托管与分账、腾讯云 IM、内容机审、六类任务模板（直播脚本灰度 20% 流量）。

**不做（Out of Scope，写入合同防止扯皮）**：原生 App、H5 独立站、案例市场、平台内置 AI 生成工具、线上开票流程（MVP 客服线下开）、保证金体系、企业月度订阅、多语言、创作者学院内容系统（仅占位入口）。

## 2. 角色与权限体系

### 2.1 角色定义

| 角色 | 获得方式 | 说明 |
|---|---|---|
| 游客 | 未登录 | 仅可浏览任务广场，操作时引导登录 |
| 创作者 | 登录后选择 / 切换 | 接单前必须完成实名认证（身份证二要素） |
| 商家 | 登录后选择 / 切换 | 发布任务前必须完成企业认证（营业执照 OCR + 人工审核 ≤4h） |
| 运营（后台） | 超管分配 | 审核、仲裁、用户管理 |
| 超级管理员 | 系统内置 | 运营全部权限 + 敏感配置二级确认 + 权限分配 |

### 2.2 权限矩阵

| 功能 | 游客 | 创作者 | 商家 | 运营 | 超管 |
|---|---|---|---|---|---|
| 浏览任务广场 | ✓（部分脱敏） | ✓ | ✓ | ✓ | ✓ |
| 抢单/投标 | — | ✓（需实名） | — | — | — |
| 发布任务 | — | — | ✓（需企业认证） | — | — |
| 管理后台 | — | — | — | ✓ | ✓ |
| 敏感配置修改（佣金/提现） | — | — | — | 提交 | 确认生效 |

### 2.3 一账号双角色

同一微信账号可同时开通创作者与商家身份，首次登录选择主角色（P01），「我的」页一键切换（P12）。两身份数据隔离：订单、钱包流水、信用分各自独立；企业认证与实名认证可并存。**切换角色需二次确认弹窗**，防止误操作。

## 3. 全局业务规则（开发必读）

### 3.1 任务状态机

```
草稿 ──提交──▶ 待支付 ──支付成功──▶ 审核中 ──机审通过──▶ 招募中 ──抢单成功/中标──▶ 进行中
                  │                    │                                          │
                  │超时未支付24h         │机审驳回                                    │创作者提交作品
                  ▼                    ▼                                          ▼
               已关闭              已驳回(退款)                                待验收 ──商家通过──▶ 已完成(分账)
                                                                                         │
                                    招募中 ──超时无人接/商家撤稿──▶ 已取消(退款)             ├─任一方发起──▶ 纠纷中 ──裁决──▶ 已完成/已退款
                                                                                         └─商家驳回──▶ 进行中(轮次-1)
```

| 状态 | 英文标识 | 进入条件 | 允许的操作 |
|---|---|---|---|
| 草稿 | draft | 填写中未提交 | 编辑、删除 |
| 待支付 | unpaid | 提交未支付 | 支付（24h 超时自动关闭） |
| 审核中 | auditing | 支付成功 | 平台机审+人工（≤30 分钟） |
| 招募中 | recruiting | 审核通过上架 | 创作者可见可接；商家可撤稿（有人接单后撤稿扣违约金） |
| 进行中 | working | 抢单成功 / 中标 | IM 沟通、提交作品、申请延期 |
| 待验收 | delivered | 作品提交（机审通过后转商家） | 验收/驳回；72h 超时自动验收 |
| 已完成 | completed | 验收通过/自动验收/裁决放款 | 分账、互评（7 天） |
| 纠纷中 | disputed | 任一方在待验收/进行中发起 | 平台仲裁（处理时限 48h） |
| 已退款 | refunded | 撤稿/流拍/仲裁退款 | 原路退回，记录违约金 |

> 一口价多名额：每名额独立订单，全部名额被占用后任务自动结束招募。投标流拍：招募期结束无人中标 → 自动全额退款。

### 3.2 订单状态机（创作者视角）

待交付 →（提交作品+机审通过）→ 待验收 →（驳回）→ 待交付(轮次−1) →（验收通过）→ 已完成(分账入账)。
异常：超时(可申请延期 1 次)、纠纷中、延迟放款(风控命中：分账入"冻结"，24h 后自动解冻)、已取消(全额退款+扣信用)。

### 3.3 资金规则

| 规则 | 默认值 | 说明 |
|---|---|---|
| 平台佣金率 | 15%（可配 5%–30%） | 向创作者侧收取；商家侧服务费为 0 |
| 托管 | 支付即全额托管 | 微信支付电商收付通；**平台公户不得经手交易资金** |
| 分账时机 | 验收通过即时 | 创作者实得 = 赏金 × (1−15%)，入余额可提现 |
| 延迟放款 | 新账号首单延迟 24h | 命中风控（新设备/异常行为）同样适用，状态显示"冻结中" |
| 商家撤稿违约金 | 10%（可配） | 有人接单后撤稿扣除，进入创作者补偿池（平台运营可分配） |
| 创作者超时取消 | 全额退款 | 创作者扣信用 20 分 |
| 仲裁退款 | 全额/部分 | 裁决书确认后 T+1 原路退回 |
| 赏金上下限 | ¥30 – ¥50,000/单 | 超上限引导联系客服走定制流程 |

### 3.4 超时规则汇总（全部后台可配）

| 环节 | 默认时长 | 超时后果 |
|---|---|---|
| 任务支付 | 24h | 自动关闭 |
| 任务机审 | 自动 ≤10 分钟；命中转人工 ≤30 分钟 | SLA 超时提醒运营 |
| 投标有效期 | 72h | 未中标自动失效并通知 |
| 中标等待商家确认 | 24h（比稿模式商家已选人未确认） | 自动确认 |
| 交付期限 | 商家设定（1/2/3/5/7 天） | 创作者可申请延期 1 次 ≤48h（商家 12h 未处理视为同意）；超时商家可取消退款 |
| 驳回后响应 | 创作者 48h 内重新提交 | 超时按交付超时处理 |
| 商家验收 | 72h | **自动验收通过并分账** |
| 评价期 | 验收后 7 天 | 未评价默认 5 星好评（无文字） |
| 提现打款 | T+1（工作日） | 见 3.7 |

### 3.5 修改轮次规则

- 免费轮次默认 2（0–5 可选），任务发布时确定并在详情页展示
- 每次驳回消耗 1 轮，驳回必须填写原因（≥10 字）；最后一轮时双方均收到强提醒
- 轮次用尽后：商家可"加钱续轮"（按赏金 10%/轮，生成追加支付单）；或直接验收；或走仲裁
- 版本链：所有提交与驳回记录永久保留（纠纷仲裁依据）

### 3.6 信用分与等级

**信用分**（初始 100，范围 0–120）：

| 行为 | 分值 |
|---|---|
| 超时未交付 / 超时未响应驳回 | −20 |
| 仲裁判责 | −30 |
| IM 发送联系方式（确认跳单意图） | −15/次，累计 3 次封号 |
| 确认跳单（站外交易被证实） | −50 + 封禁 7 天，二次永久 |
| 按时交付 | +1（每日上限 1 次） |
| 获 5 星好评 | +1 |

分数影响：≥95 派单排序加权；<80 不可接"认证专享"任务；<60 单笔接单上限 ¥200；<40 禁止接单（可申诉）。

**创作者等级**：

| 等级 | 条件 | 权益 |
|---|---|---|
| Lv.1 见习 | 实名认证 | 单笔接单上限 ¥500 |
| Lv.2 进阶 | 成单 ≥5 且好评率 ≥4.5 | 上限 ¥3,000 |
| Lv.3 认证 | 作品集 ≥9 件 + 平台人工审核（样片/工具核验） | 无上限、认证标识、认证专享任务、优先派单 |

### 3.7 提现规则

实名认证 + 银行卡四要素校验通过才可提现；单笔最低 ¥100；每日 1 笔；T+1 到账（工作日）；手续费平台承担（成本摊入佣金）。命中风控（新账号首单、纠纷判责未满 30 天、同设备多账号）→ 延迟 24h 并转人工复核（A03）。

### 3.8 防跳单规则

IM 消息实时过滤：手机号（11 位）、微信号模式、QQ 号、"加微/vx/wx/威信/❤"等变体词库（后台可维护）→ 消息**不送达**+会话内系统警示（见 P11）；累计 3 次触发跳单警告处罚。任务详情、IM、支付页三处固定展示"平台外交易无保障"提示。

## 4. 功能需求 · 微信小程序端（P01–P12）

> 每个模块给出：对应原型屏、描述、关键交互、字段/规则、异常分支。原型图标注了页面结构与默认状态，与本节冲突时以本节文字为准。

### 4.1 登录与角色选择【P01】

- 微信授权登录（openid/unionid），首次登录强制选择主角色（商家/创作者卡片单选，可切换选中态）
- 未选角色前所有交易功能不可用；游客态浏览广场时任务卡片隐藏商家真实名称（显示"已认证商家"）
- 协议勾选：未勾选不可点击登录按钮（置灰态）；协议链接内嵌 H5 展示
- 异常：微信授权拒绝 → 提示并停留在本页；账号被封禁 → 登录成功后弹封禁原因与申诉入口

### 4.2 任务广场与搜索【P02】

- 顶部搜索（任务标题/类目关键词，历史记录 10 条）；分类 chips：全部/商品图/模特换装/短视频/详情页/文案/直播脚本（灰度类目仅对 20% 用户可见）
- 排序：综合（默认，权重=赏金×0.3+新鲜度×0.4+商家信用×0.3）/赏金最高/最新发布/即将截止
- 任务卡片字段：标题（≤40 字截断）、类目标签、接单模式标签、免费修改轮次、赏金（红色醒目）、截止倒结算、名额/投标数、商家信用分
- 列表分页 10 条/次，下拉刷新、触底加载；已满员/已结束任务置灰但可见（展示"已结束"）
- 敏感逻辑：任务状态为招募中才可点击进入详情；其他状态点击提示

### 4.3 任务详情【P03】

- 结构：商家信息卡（认证标识、信用分、历史成单、好评率，点击进商家主页）→ 标题/标签 → 三格数据（赏金已托管/交付截止/名额）→ 需求分组（需求描述、交付要求、参考素材）→ 规则提示条
- 素材防盗链：参考素材显示缩略图+水印，**接单后方可查看/下载原图**（COS 签名 URL，有效期 2h）
- 底部操作条（按接单模式与身份动态渲染）：
  - 一口价 + 创作者（未实名 → 引导实名；等级上限不足 → 提示升级；名额满 → 置灰）：立即抢单（二次确认弹窗：倒计时 3s 防误触，展示赏金/期限/轮次）
  - 比稿 + 创作者：立即投标 → P04
  - 商家身份查看：不显示接单按钮，显示"分享/编辑"
- 抢单成功 → 订单创建 → 跳转 P08；失败（并发抢单）→ 提示"手慢了，名额已被抢"返回广场

### 4.4 投标【P04】

- 字段：报价（必填，≤ 商家赏金即 ≤800；低于赏金 50% 时提示"过低报价可能影响信任分"）、方案说明（必填 20–500 字）、交付工期（1/2/3/自定义 ≤ 任务期限）、附件作品集（图片/压缩包 ≤20MB，选填）
- 规则：每任务限投 1 次不可撤回；投标有效期内可被中标；中标后 24h 内商家确认
- 提交成功 → 收藏该任务（状态变更订阅消息通知：中标/流拍）
- 异常：等级上限不足禁止提交；任务招募期截止后投标入口关闭

### 4.5 发布任务【P05 / P06】

- 前置：企业认证未完成 → 引导认证（拍照营业执照 OCR + 法人信息 + 人工审核 ≤4h，驳回可重提 3 次）
- P05 模板选择：六类模板卡片（icon+名称+说明+起价），点击进入 P06 表单；「自定义需求」入口 → 客服会话
- P06 表单为**模板动态渲染**（字段定义见附录 A），通用字段：
  - 任务标题（5–50 字必填）、商品链接（选填，粘贴后自动读取商品标题与主图，失败提示手动输入）
  - 需求描述（10–2000 字必填）、素材上传（必填 ≥1 个，≤20 个，图片/文档 ≤20MB，视频 ≤500MB）
  - 交付要求（选填 ≤500 字，支持"插入模板"：尺寸规范/禁用真人脸/需要源文件/品牌色卡）
  - 赏金（必填，展示类目指导价区间；区间外二次确认弹窗）
  - 完成期限（1/2/3/5/7 天）、免费修改轮次（0–5 默认 2）、接单模式（一口价 1 人 / 比稿 1–3 人）
  - 高级开关：仅认证创作者可接（默认关）、允许创作者申请延期（默认开）、定向邀请创作者（≤5 人，从收藏/历史合作选择，MVP 简化为收藏列表）
- 费用区实时联动：应付合计 = 赏金（商家侧服务费 0）
- 支付：拉起微信支付（电商收付通下单）→ 成功 → 任务进入审核（约 10 分钟）→ 订阅消息通知上架结果
- 异常：支付失败/取消 → 任务停留"待支付"（24h 关闭）；审核驳回 → 全额自动退款 + 驳回原因（敏感词高亮定位），商家修改后免费重新提交 1 次

### 4.6 我的订单（创作者）【P07】

- 顶部四格：累计收入/本月收入/累计成单/好评率
- 状态 tab：全部/待交付（角标数）/待验收/已完成；订单卡：标题、状态 chip、赏金、剩余时间（<12h 变红）、操作按钮（去交付/联系商家/催验收/申请延期/评价）
- 「催验收」：每次订单限 1 次，向商家发订阅消息；72h 自动验收倒计时始终展示

### 4.7 订单详情与作品提交【P08】

- 头部：状态、订单号（可复制）、赏金、交付倒计时（<12h 红，<2h 闪烁）
- 需求速览卡 + IM 入口；版本时间线（v1 已提交/已驳回含原因、v2 待提交，驳回原因支持图片标注）
- 提交表单：作品文件（图片/压缩包/视频，≤20 个）+ 修改说明（选填 ≤500 字）
- **AIGC 声明勾选（强制，未勾选不可提交）**：承诺 AI 辅助生成+人工精修、无侵权内容、同意平台标识规范
- 提交 → 机审（天御：图片+文本，≤2 分钟）→ 通过转商家待验收；命中违规 → 拦截并提示具体项（可修改后重提，不消耗轮次；恶意提交 3 次扣信用 10 分）
- 申请延期：每订单 1 次，≤48h，商家 12h 未处理视为同意（订阅消息通知双方）

### 4.8 验收（商家）【P09】

- 作品九宫格预览（点击全屏），每张 AI 生成内容显示「AI 生成」角标（合规要求，平台强制）
- 创作者卡（等级/好评率/响应时长）；v 版本与剩余轮次
- 验收 checklist：按交付要求自动生成勾选项（辅助非强制）
- 操作：验收通过（二次确认弹窗展示分账明细：赏金 ¥600 → 创作者 ¥510 / 平台 ¥90）→ 即时分账 → 双方进入互评；驳回（必填原因 ≥10 字，可附标注图）
- 72h 自动验收提示条常驻；自动验收订单同样分账并通知双方

### 4.9 评价（横切功能，入口在验收后）

- 双向互评：5 星 + 标签（商家评创作者：出图快/还原度高/沟通顺畅/专业靠谱；创作者评商家：需求清晰/付款爽快/沟通及时）+ 文字 15–500 字 + 图（选填 ≤3 张）
- 7 天未评 → 系统默认 5 星（无文字无标签，标注"系统默认"）
- 评价不可删除；被评方可回复一次；不实评价可申诉（运营复核）

### 4.10 钱包与提现【P10】

- 钱包卡：可提现余额/冻结中（含明细入口）/累计收入
- 提现表单：金额（默认全部，校验：≥¥100、≤余额、每日 1 笔）、银行卡（四要素校验，支持添加多张）
- 流水类型：分账入账/提现/提现驳回退回/违约金调整/仲裁调整；每笔流水关联订单号
- 提现记录状态：审核中/已打款（附打款回执单号）/已驳回（原因）

### 4.11 消息与 IM【P11】

- 会话列表：任务相关会话展示订单状态 chip；系统通知（上架结果/中标/验收/分账/提现）聚合为官方会话
- 聊天：文本/图片/文件（≤20MB）；快捷回复常用语（平台预设 8 条+自定义）；敏感词过滤见 §3.8，被拦截消息对发送方显示为"已屏蔽"系统条
- IM 记录永久留存，仲裁时运营可调取（用户端提示"聊天记录将作为纠纷依据"）
- 订阅消息触发点：任务上架/驳回、抢单成功、中标、新作品提交、验收通过/驳回、分账到账、提现打款、纠纷进展（共 9 类模板，需提前向微信申请）

### 4.12 个人中心【P12】

- 创作者主页：头像/昵称/等级徽章/信用分/可接单上限提示、四格数据、作品集管理（上传 ≤30 件，标注工具与工时，审核后展示）、身份切换入口
- 功能入口：我的订单/我的投标/钱包/实名认证/创作者学院（占位）/设置
- 实名认证：姓名+身份证号二要素 + 人脸核身（可选增强，MVP 仅二要素）；信息加密存储，通过后不可修改（需客服）

## 10. 验收标准

1. **功能验收**：按本 PRD + 原型逐条比对，功能点覆盖率 100%；管理后台配置项全部可用且热生效。
2. **流程验收**：走通 6 条完整链路——①一口价全流程 ②比稿全流程 ③驳回→续轮→验收 ④超时自动验收 ⑤纠纷仲裁退款 ⑥提现打款（沙箱环境），每条留存录屏。
3. **缺陷分级**：A 级（资金错误/支付失败/崩溃/数据错乱）0 容忍，存在即不验收；B 级（主流程阻塞）修复 ≥ 全部后才验收；C 级（体验问题）≤20 个限期修复；D 级（建议）不阻塞。
4. **性能验收**：压测报告（100 并发，错误率 0，P95 < 500ms）；小程序审核通过并线上可搜。
5. **交付物**：源码（含 SQL 与初始化数据）、Apifox 接口文档、部署手册（Docker Compose 一键部署）、测试用例与报告、3 分钟全流程演示视频。
6. **验收流程**：乙方提测 → 需求方按用例回归 → 出具验收单 → 尾款。免费维护期 3 个月（自验收单签署起）。
